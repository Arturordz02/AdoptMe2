================================================================================
                    ADOPTME - PLATAFORMA DE ADOPCIÓN RESPONSABLE
================================================================================

1. ARQUITECTURA TÉCNICA OFICIAL
--------------------------------------------------------------------------------
AdoptMe es una plataforma integral para la adopción responsable de mascotas,
desarrollada con una arquitectura cliente-servidor desacoplada:

- Frontend Android:
  * Lenguaje: Kotlin.
  * Interfaz de usuario: Jetpack Compose declarativo y Material 3.
  * Identificador de aplicación: com.example.adoptme.
  * Conectividad HTTP: Retrofit 2 + OkHttp 4 + Gson Converter.
  * Carga de imágenes: Coil Compose.
  * Mapas y geolocalización: Google Maps Platform (Play Services Maps + Maps Compose).
  * Base de datos local: Room Database (MascotaVisitada) + Jetpack DataStore + SharedPreferences.
  * Chat y notificaciones: Locales al dispositivo, con persistencia aislada por cuenta de usuario.

- Backend Web API:
  * Framework: ASP.NET Core 8 Web API (.NET 8.0).
  * Servidor en producción: Render Web Service (https://adoptme2.onrender.com/).
  * Base de datos en la nube: PostgreSQL 16 hospedado en Neon Serverless.
  * Almacenamiento multimedia: Cloudinary para imágenes persistentes de mascotas y logos.
  * Autenticación y Autorización: JWT Bearer multirol (Adoptante, Centro, Administrador).
  * Documentación interactiva: Swagger / OpenAPI.

- Aclaraciones de infraestructura:
  * Firebase: NO se utiliza en el proyecto.
  * Azure: NO forma parte de la arquitectura final del proyecto.


2. GUÍA DE APERTURA Y EJECUCIÓN
--------------------------------------------------------------------------------
A. PROYECTO ANDROID (Carpeta "Android"):
   - Abrir Android Studio (Ladybug, Koala, Meerkat o superior).
   - Seleccionar "Open" y elegir la carpeta "Android" del repositorio.
   - Requisito: JDK 17 o JDK 21 configurado como Gradle JDK.
   - Entorno de ejecución:
     * Por defecto, la aplicación se compila y ejecuta apuntando directamente
       a la API en la nube (https://adoptme2.onrender.com/). No requiere
       iniciar dotnet localmente ni ejecutar 'adb reverse'.
     * La variante Release siempre apunta obligatoriamente a Render.
     * Modo local opcional (opt-in): para depurar contra un backend ASP.NET local
       en http://127.0.0.1:5217/, se debe compilar explícitamente con el parámetro:
       -PusarBackendLocal=true

B. PROYECTO BACKEND (Carpeta "Backend"):
   - Abrir "Backend/AdoptMe.sln" en Visual Studio 2022 o VS Code.
   - Requisito: .NET 8.0 SDK instalado.
   - Compilación y ejecución de pruebas:
     dotnet build Backend/AdoptMe.sln
     dotnet test Backend/AdoptMe.sln


3. ROLES Y FUNCIONALIDADES DEL SISTEMA
--------------------------------------------------------------------------------
- Adoptante:
  * Catálogo público de mascotas con filtrado por especie, ubicación y edad.
  * Mapa interactivo de centros de adopción y mascotas geolocalizadas.
  * Formulario de solicitud de adopción responsable y test de compatibilidad.
  * Bandeja local de notificaciones y mensajería directa con centros de adopción.

- Centro de Adopción:
  * Registro institucional diferenciado y gestión de perfil.
  * Publicación de mascotas vinculadas al centro con fotografía persistente en Cloudinary.
  * Panel operativo con métricas institucionales y bandeja de postulaciones.
  * Notificaciones de estado de aprobación o suspensión operativa.

- Administrador:
  * Revisión y aprobación / rechazo justificado de solicitudes de centros.
  * Suspensión operativa formal de centros con motivo obligatorio y registro de auditoría.
  * Reactivación administrativa de centros suspendidos.
  * Vinculación responsable 1:1 de usuarios titulares a centros sin propietario.
